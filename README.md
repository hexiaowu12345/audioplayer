# 音频播放器

一个主要用 Python 编写的命令行音乐播放器，可以在 Termux / Android、Windows 和桌面 Linux 上运行。

项目的目标很简单：**解出来是什么就送什么**——尽量少做重采样和多余处理；同时把扫描、歌单、循环、失败保护这些日常操作做得顺手。

代码由 AI 辅助编写，目前仍在持续修复和改进中，欢迎一起完善。

> ⚠️ **重要提醒：USB 独占输出目前存在明显缺陷，等待修复。**
> 在作者本人的手机上实测：最常见的是独占失败（授权后无法接管，直接回退系统输出）；
> 即使偶尔接管成功，播放声音也会出现明显的撕裂和切断。
> 该功能目前**不建议日常使用**，请保持默认关闭（`usb off`）。

## 功能

- **曲库扫描**：mutagen 优先读标签、ffprobe 兜底，带缓存；跨平台或换设备后路径失效会自动重扫
- **播放控制**：下一首 / 上一首 / 重播 / 跳到第 N 首 / 快进快退 / 暂停继续（直接回车）
- **循环模式**：单曲循环、列表循环、随机播放
- **歌单**：新建、增删、重命名、切换，只记录路径，不复制也不删除歌曲文件
- **歌曲信息**：`info` 查看标签、编码、位深、采样率、码率、时长、文件大小
- **播放熔断**：连续 5 首播放失败自动暂停，等你决定继续还是退出，不会一路刷屏
- **输出通道**：默认走 AudioTrack / AAudio 直通；可开启「极致完美输出」关闭一切附加处理
- **USB 独占输出（实验性，默认关闭，已知有缺陷）**：无 root 抢占 USB 声卡直接送 PCM，稳定性差，详见下文「已知限制」
- **跨平台**：Termux / Windows / 桌面 Linux 共用主体代码，平台不支持的功能自动降级

## 环境要求

- Python 3.9 或更高
- 播放：`mpv`（推荐）或 `ffplay`
- 元数据：`mutagen`（推荐，扫描明显更快）或 `ffprobe`
- 以上缺一个也能启动，程序会给出提示并自动降级

## 使用方法

```bash
git clone https://github.com/hexiaowu12345/audioplayer.git
cd audioplayer

python run.py                 # 使用各平台的默认音乐目录
python run.py /sdcard/qqmusic # 或指定目录（可以传多个）
```

依赖安装示例：

```bash
# Termux
pkg install python ffmpeg mpv
pip install mutagen

# Ubuntu / Debian
sudo apt install python3 ffmpeg mpv
pip install mutagen

# Windows：把 ffmpeg、mpv 加入 PATH，然后
pip install mutagen
```

## 常用命令

| 命令 | 作用 |
| --- | --- |
| 直接回车 | 暂停 / 继续 |
| `next` / `n` | 下一首（`next -n3` 跳 3 首） |
| `last` / `l` | 上一首 |
| `replay` / `r` | 重播当前这首 |
| `switch -n3` / `s -n3` | 切换到第 3 首 |
| `forward 30` / `+30` | 快进 30 秒（`-15` 后退 15 秒） |
| `loop` / `lp` | 单曲循环开关 |
| `listloop` / `lc` | 列表循环开关 |
| `random` / `rnd` | 随机播放开关 |
| `info` / `i` | 当前歌曲详细信息 |
| `status` / `st` | 播放状态 |
| `ls` | 查看播放列表 |
| `pl` | 歌单（`pl help` 看用法） |
| `vol` | 音量（`vol 60` / `vol hw` / `vol sw`） |
| `audio` | 输出通道：AAudio 直通 / 系统默认 |
| `perfect` | 极致完美输出开关 |
| `rescan` | 重新扫描曲库 |
| `compat` | 跨平台兼容自检 |
| `usb` | USB 独占输出（实验，`usb on|off`，**慎用**） |
| `help` | 帮助（`help play` / `help pl` / `help set` / `help sys`） |
| `quit` / `q` | 退出 |

## 目录结构

```
core/     扫描、元数据、播放控制、命令引擎
module/   具体命令：播放控制、歌单、系统指令、帮助
utils/    输出通道、USB、存储、格式化等工具
strings/  界面文案
tools/    USB 探针 / 独占输出（C 语言）与自检脚本
```

## 已知限制

- **USB 独占输出（等待修复）**：作者在本人手机上实测存在明显问题——
  - 最常见的是**独占失败**：弹窗授权后仍无法接管设备，直接回退系统输出
  - 即使偶发接管成功，**播放声音会出现明显的撕裂和切断**
  - 结论：当前版本不建议日常使用，默认关闭；修复前请勿依赖该功能
- 部分内核的 usbfs 限制导致采样率不可调、退出后需拔插恢复（详见 `改进项目.txt`）
- 暂无自动化测试，目前依赖手工测试记录（见 `改进项目.txt`）
- 不同平台依赖不同，首次运行建议先跑 `compat` 自检
